# Безопасный массив (SafeArray)

Лабораторная работа №3: работа со структурами и безопасный доступ к памяти.

## Возможности
- Структура SafeArray с динамическим массивом
- Создание массива через createArray()
- Безопасный доступ через getElement() с проверкой границ
- Использование getElement() слева от знака равенства
- Вывод массива через printSafe()
- Изменение размера через resizeArray()
- Корректное освобождение памяти

## Требования
- Компилятор с поддержкой C++14
- Стандарт: **C++14**

## Сборка и запуск
Команда компиляции: g++ -std=c++14 -O2 -Wall 1_3_laba.cpp -o 1_3_laba.exe
Запуск: .\1_3_laba.exe

## Ключевые моменты
- Структура SafeArray содержит указатель и размер
- getElement() возвращает ссылку (int&) для использования слева от =
- Проверка границ с возвратом ссылки на static dummy
- resizeArray() корректно копирует элементы и обнуляет новые
- deleteArray() освобождает память и обнуляет указатель
